# Maquette DIAMS Tools

Prérequis : Node.js 22.18 ou plus récent et npm.

```sh
npm ci --ignore-scripts
npm run dev
```

Ouvrir l'adresse locale indiquée par Vite. Pour vérifier le projet :

```sh
npm test
npm run build
```

Les données de démonstration sont fictives et enregistrées dans le navigateur.
Cette version utilise un stockage séparé de la version précédente. Elle ne
dispose ni de connexion à un système métier ni d'authentification ; ne pas y
saisir de données personnelles ou confidentielles.
